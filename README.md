# University of the People Term Resources

This repository is a personal study archive for the current term at University of the People. It brings together the main course materials, weekly resources, assignment files, and supporting notes for the academic work in this term.

## Term Overview

This term includes four courses that support the academic path in computer science and mathematics:

1. CS 1103 Programming 2
2. CS 2203 Databases 1
3. CS 2204 Communications and Networking
4. MATH 1280 Introduction to Statistics

## Purpose of This Repository

The goal of this repository is to keep every course organized in one place. It is designed to help with study planning, assignment preparation, and review before deadlines. Each folder reflects a different course and contains the materials related to that subject.

## Course Resources

The term folders are organized by course code and academic calendar. The structure helps maintain a simple and consistent workflow for each class.

### CS 1103 Programming 2

This course focuses on programming skills, software logic, and practical problem solving. The resources in this folder are intended to support learning, revision, and completion of programming assignments.

### CS 2203 Databases 1

This course introduces database concepts, design principles, and data management practices. The materials in this section are meant to support assignments, weekly learning tasks, and course review.

### CS 2204 Communications and Networking

This course covers communication systems, networking fundamentals, and how digital systems connect. The folder contains resources for assignments, discussions, and study preparation.

### MATH 1280 Introduction to Statistics

This course introduces statistical reasoning, data interpretation, and quantitative analysis. The study files in this folder support weekly learning, assignment work, and review of statistical methods.

## Repository Structure

The repository is organized by course and week. This makes it easier to locate study materials, notes, and assignments for each class. Weekly folders keep the workload structured and easier to follow during the term.

## How to Use This Repository

Use this repository as a study and organization hub for the current term.

1. Open the course folder that matches your current task.
2. Review the syllabus and weekly materials before starting work.
3. Save assignments, draft work, and final submissions in the correct folder.
4. Keep notes, readings, and references in the same place for easier revision.
5. Use the weekly organization to stay on track with deadlines and academic goals.
